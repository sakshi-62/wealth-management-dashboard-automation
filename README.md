# wealth-management-dashboard-automation
QA Automation Project using Selenium WebDriver, Java, Maven, MySQL and JIRA. Includes test cases, test documentation, automation scripts and sample execution reports

## Project Overview
This project focuses on testing a fictional Wealth Management Dashboard application designed to help customers monitor investment accounts, portfolio values, holdings and financial transactions.

## Project Objectives
- Validate login and authentication functionality.
- Verify portfolio summary and account information.
- Test investment holdings and market value calculations.
- Validate transaction history and filtering.
- Perform positive and negative testing.
- Document defects and test results.
- Prepare database validation queries.
- Develop Selenium automation scripts using Java.

## Application Modules
1. Login
2. Dashboard
3. Account Management
4. Portfolio
5. Investment Holdings
6. Transactions
7. Reports
8. Customer Profile
